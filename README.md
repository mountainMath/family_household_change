
# The new rules: housing shortage as an explanation for family and household change across large metro areas in Canada, 1981-2021

This is the code repository for the [The History of the Family](https://doi.org/10.1080/1081602X.2024.2448986) paper "The new rules: housing shortage as an explanation for family and household change across large metro areas in Canada, 1981-2021"

Please navigate to the [GitHub pages of this project](https://mountainmath.github.io/family_household_change/) for links to the paper and code.
